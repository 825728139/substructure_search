# 合成参考结果评分与调参

评分配置是[ranking_weights.yaml](../src/reaction_reference/resources/ranking_weights.yaml)。文件内逐项写有中文化学依据、目的、计算方式、调高后的影响和局限；它控制实际运行数值，不是说明性模板。

## 计算方式

通过现有主推荐资格门槛后，按**各维度原值乘权重的总和**排序；总分完全相同才按稳定ID排列。不再用方法标签、局部环境差异等逐项优先级排序，也不根据命中的查询层级额外加分。同一反应被多个查询发现不会重复累加分数。

基础权重合计100：母核覆盖28、目标整体覆盖17、反应中心位置20、双侧覆盖10、连接环境8、方法贡献7、来源证据5、指纹相似度2、映射确定性3。普通基础分范围0～100。

完整目标且有来源获得证据时，默认额外奖励100分；只有产物结构相同不触发该奖励。用户明确选择操作偏好或实验适配时，分别启用对应的附加分。分数是可解释的检索排序启发式，不是合成成功概率，不代表安全性或条件可迁移性。

## 母核与支链方向

环状目标合并共享原子的完整环系。环原子权重由配置中的基础值与独立环数系数计算，避免普通乙酯片段压过桥环、稠环参考。这只是拓扑近似；并不宣称自动识别出了唯一的化学家主观母核。

无环目标以官能团锚点之间的连接路径为骨架，缺少锚点时使用完整重原子框架。支链头部包含骨架边界及直接相连功能单元，扩展不会沿重叠官能团一路传播到整条支链。酯的O—乙基、醚的远端烷基不计为连接头部。

中心位置默认原值：精确投影的母核内部1、骨架与支链头部0.8；位置不唯一但区域共识确认时，母核内部0.8、头部0.6；远端或无区域支持的未解决位置0。位置值乘以20分权重。映射确定性另占3分，精确位置原值1、区域共识0.7、其他歧义0.2、未知0。母核覆盖、整体覆盖和位置只取同一个具体方法见证，不跨多个映射或多个参考拼接覆盖。

评分沿用`target_input_smiles`的原始原子编号；规范SMILES只用于身份比较。首次检索和冻结重排都保留该索引约定，避免把某个见证指向的桥环位置误套到规范化后的其他原子上。

## 修改与审核

1. 修改YAML中需要调整的权重、中心位置值或归一化参数。基础权重必须合计100，分项原值必须在0～1之间，尺度必须为正数。文件也控制环原子权重、来源证据值和操作偏好归一化参数。
2. 在仓库根目录校验配置：

   ```bash
   implementation/.venv/bin/python -c 'from reaction_reference.ranking.scoring import scoring_policy; p=scoring_policy(); print(p["version"], p["weights"], p["config_sha256"])'
   ```

3. 修改实质规则时更新`version`，重启服务后重新检索或重新排序。配置按进程缓存，不会在同一个运行任务中途热切换。旧快照保留原评分，刷新网页不会擅自重算历史结果。
4. Demo每条推荐显示总分、母核覆盖、中心位置，展开“评分构成”可核对原值、权重和得分。完整结果的`ranking_features.score`保留分项、版本及配置SHA-256；`target_scaffold_relevance`保留目标索引和使用的见证ID。
5. 同时比较多个目标，并保留负例：桥环构建应高于孤立乙酯尾部方法；简单酰胺例中也要维持合理的底物迁移顺序。提高一个分项可能牺牲另一类检索，不能仅凭单个分子校准。

配置会严格拒绝未知/缺失分项、重复键、负权重、非数值、NaN/Infinity、错误权重合计和不合法归一化尺度。解析采用安全YAML，不允许执行对象标签；配置不合法直接报错，不静默回退成其他权重。

## 验证边界

当前保留了用户实际七条酰胺结果和三条桥环目标结果作回归：酰胺仍按原1、4、3、7排列，桥环方法高于乙酯尾部。还测试了切换权重确实可以改变排序，避免实现里隐藏一套不可调整的优先级。

这些是开发回归，不是独立专家质量评测。原始结构抽取错误、映射不完整、电子效应、位阻和反应条件迁移仍需独立核查。主推荐资格过滤继续与评分分开：没有目标反应中心证据的普通片段不会仅凭高分绕过门槛，原始候选和原因仍在完整资料包。

## 区域一致但精确位置有歧义

来源新键已经识别，但产物内部对应存在歧义时，保留互斥的`projection_alternatives`，确定的`formed_target_bonds`仍为空。只有同一见证下的对应枚举完整、只有一个同身份映射产物实例、每种解释都有目标成键，且所有候选成键都属于同一个具体母核或直接连接头部区域，才设置`region_consensus.state=confirmed`。

该区域方法可以进入主推荐，贡献仍为图推定，按YAML中的区域位置分值和映射确定性计分。若对应跨不同母核、混有目标外/尾部解释、某解释没有目标成键，或超过128个对应上限，不认定区域共识。不能把多个候选位置并成多根已形成键，也不能据此升级来源获得证据。

真实先例6766761的8个对应归并成两种单键解释：目标14—15或14—17，均处于同一含氮桥环，因此保留为区域级桥环构建方法。此前明确无关的硝基还原、结构使用先例仍不占方法主推荐。旧快照不会自动重新分析；需重新检索以应用该修复。
