# 实现与验证范围

2026-10-30，版本 0.1.0。首版已可从目标 SMILES 运行到参考资料包，CLI、SDK、API 和内部页面共用检索流程。这里区分已运行的能力与仍需补充的化学覆盖、资料来源和发布验证；不把整个设计的未来验收要求记为已全部完成。

| 模块 | 已实现 | 当前边界 |
|---|---|---|
| 目标与契约 | 严格字段/预算校验，单一具体有机目标，同位素、完整目标立体要求，JSON Schema/OpenAPI | 在线目标最多 500 重原子；多组分意图、增强立体组需明确处理，当前拒绝 |
| 查询规划 | 整体、核心、分片三层，严格目标补查，完整环系、无环锚点、官能团邻域和非环边界片段，缺失 R 位点定向家族 | 有限的官能团/规则集合；生成家族数不是化学上所有可能骨架总数 |
| Markush 核验 | 原生 generic 属性恢复，多 R、可选 H、完整支链类别/长度、R 相等关系、桥连块、额外核心边、对称映射 | R 相等不支持桥连；任意可变路径/专利自然语言 Markush 未支持 |
| 联合覆盖 | 每个具体材料及一致映射的原子/键覆盖，与不同映射的位点并集分开；截断跨页累计 | 结构覆盖不等于立体结果证明，也不宣称找到所有可选家族的最大覆盖 |
| 来源 | 有限 JSONL、只读 PG、有效化学索引检查、轻量候选、命中后证据加载与缓存 | 临时 PG/RDKit 的真实 SQL 集成已验证，现库执行计划和千万级性能未验证；JSONL 不用于千万级在线扫描 |
| 候选选择 | JSONL Pattern 必要核心预筛、有限体量窗口与相似优先；PG 可用时整侧 KNN 初选，独立子结构游标，预选失败保留独立补查机会 | 近体量阈值未标注校准；PG 没有具体材料质量索引，整侧相似度不保证方法召回 |
| 实际反应分析 | 映射正整数唯一性、元素/同位素和材料端点校对；成/断键、离去边界、未跟踪片段、键级、H/电荷/自由基变化；有限共振例外 | 使用单个来源映射，复杂映射冲突返回未知；不从净反应断言单一步骤机理 |
| 方法贡献 | 实际 C–C/C–N/C–O/C–S 连接与酰基连接等粗类别、键级变化、命中后真实开/闭环；按一致见证投影目标位置，后续分片可升级贡献分类 | 图贡献与来源报告支持分开；位置歧义不硬指认；不预测反应机理或条件 |
| 单反应物替换 | 已赋予操作段落的来源、明确输入使用和产品报告；来源 radius-2 / 有限注册规则自回放，固定其余完整输入，只换一个；全产物组与完整目标校验 | 每源至多 4 个输入、选前 6 个参考、每参考至多 2 项；受全局预算限制。来源未分步、一锅多步未知等不自动迁移 |
| 证据分账 | 产品报告/分析/富集/失败/回收/冲突、输入使用、图推定、合成示例和未观察建议分开；来源哈希绑定的审核文件 | 提取产品字段不自动升级制备事实。当前真实样本尚未补充独立审核的产品观察 |
| 材料关系 | 已返回记录中产品与输入的完整身份链接、引用和支持状态 | 不把身份链接称为可直接组合的路线；主动共同中间体补查未实现 |
| 九方向排序 | 方法、迁移、反应性、证据、供应、操作、危害、产出、放大分别提供事实/未知与限制；实验限制、参考优先、操作偏好；完整目标获得记录保留与三层展示配额 | 供应、危害、监管、放大资料供应器未接入。官能团差异只是线索，电子/位阻和选择性不作预测 |
| 执行与接口 | 单协调器锁、独立计算子进程、硬超时/取消、总任务/候选/反应/映射等上限；幂等、revision、原子文件快照、固定快照分页、冻结候选重排、中断保留 | 单访问范围、单协调进程；不提供分布式队列/自动故障续接。运行目录暂需人工维护 |
| 内部查看 | 目标输入、状态、三层统计、来源材料、结构与原子高亮、反应变化、九方向解释、取消/重排/导出 | 是内部研究查看页面；不提供反应编辑器或下游模型预测界面 |

操作偏好采用一个明确但尚未校准的初始规则：只在相同方法资格、证据及信息可用分组内，比较温度区间偏离 25°C 的程度和报告时长。缺失信息不填成容易操作；这个偏好不估计实际能耗、选择性或风险。默认参考价值排序不使用这一操作偏好。

在线 PostgreSQL 召回门槛为 `final_score >= 12`：12 分保留，低分和缺失分数不返回；先过滤再执行 KNN 前 512 条截断或子结构分页。产物、反应物、严格目标和放宽查询均遵循同一门槛，统计只描述合格来源范围。来源仍为 `reaction.reactions`；新表切换另行接入。

2026-10-31 [新表只读实测](../../reviews/live_benchmark_2026_10_31/report.md)：11个目标共27次应用检索，测试连接仅重定向新表名。默认22次查询中位3.07秒、P95 5.01秒，但均因任务预算停止；55个默认前五名位置中30个经逐条化学审阅有明确方法参考价值，三个无精确先例目标为0/15。该结果不代表全库召回率或实验成功率，生产代码未改动。

## 真实目标首轮试跑

[目标集合](../evaluation/targets.jsonl)来自已读取的 300 条真实反应样本，用完整产物的结构差异进行有限选样。每个目标分别运行保留原记录与屏蔽全部生成该目标记录两种任务；[完整报告](../evaluation/sample_report.json)记录来源快照、目标哈希、实现/规则哈希、逐目标结果、范围及停止原因。

12 个保留记录任务均找到了目标结构；12 个屏蔽任务均未重新混入这些目标产物记录。部分任务触及反应或输入使用预算，结果明确为部分范围。运行耗时记录在报告中：它测的是已加载 300 条固定样本后的应用流程，存在样本缓存，不能外推为在线端到端延迟或千万级性能。

当前全部方法相关性标签为 `unreviewed`，没有计算方法精确率/召回率，也没有将未审核的产品字段计入真实制备命中。结构自命中与屏蔽隔离验证不能代替化学方法质量评测。该数据集不是独立分子系列/来源分组后的模型泛化评测。
