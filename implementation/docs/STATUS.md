# 实现与验证范围

2026-10-30，版本 0.1.0。首版已可从目标 SMILES 运行到参考资料包，CLI、SDK、API 和内部页面共用检索流程。这里区分已运行的能力与仍需补充的化学覆盖、资料来源和发布验证；不把整个设计的未来验收要求记为已全部完成。

| 模块 | 已实现 | 当前边界 |
|---|---|---|
| 目标与契约 | 严格字段/预算校验，单一具体有机目标，同位素、完整目标立体要求，JSON Schema/OpenAPI | 在线目标最多 500 重原子；多组分意图、增强立体组需明确处理，当前拒绝 |
| 查询规划 | 整体、核心、分片三层，严格目标补查，完整环系、无环锚点、官能团邻域和非环边界片段，缺失 R 位点定向家族 | 有限的官能团/规则集合；生成家族数不是化学上所有可能骨架总数 |
| Markush 核验 | 原生 generic 属性恢复，多 R、可选 H、完整支链类别/长度、R 相等关系、桥连块、额外核心边、对称映射 | R 相等不支持桥连；任意可变路径/专利自然语言 Markush 未支持 |
| 联合覆盖 | 每个具体材料及一致映射的原子/键覆盖，与不同映射的位点并集分开；截断跨页累计 | 结构覆盖不等于立体结果证明，也不宣称找到所有可选家族的最大覆盖 |
| 来源 | 有限 JSONL、只读 PG、有效化学索引检查、轻量候选、命中后证据加载与缓存 | PG 在线查询尚未在具备化学索引的现库验证；JSONL 不用于千万级在线扫描 |
| 候选选择 | JSONL Pattern 必要核心预筛、有限体量窗口与相似优先；PG 可用时整侧 KNN 初选，独立子结构游标，预选失败保留独立补查机会 | 近体量阈值未标注校准；PG 没有具体材料质量索引，整侧相似度不保证方法召回 |
| 实际反应分析 | 映射正整数唯一性、元素/同位素和材料端点校对；成/断键、离去边界、未跟踪片段、键级、H/电荷/自由基变化；有限共振例外 | 使用单个来源映射，复杂映射冲突返回未知；不从净反应断言单一步骤机理 |
| 方法贡献 | 实际 C–C/C–N/C–O/C–S 连接与酰基连接等粗类别、键级变化、命中后真实开/闭环；按一致见证投影目标位置，后续分片可升级贡献分类 | 图贡献与来源报告支持分开；位置歧义不硬指认；不预测反应机理或条件 |
| 单反应物替换 | 已赋予操作段落的来源、明确输入使用和产品报告；来源 radius-2 / 有限注册规则自回放，固定其余完整输入，只换一个；全产物组与完整目标校验 | 每源至多 4 个输入、选前 6 个参考、每参考至多 2 项；受全局预算限制。来源未分步、一锅多步未知等不自动迁移 |
| 证据分账 | 产品报告/分析/富集/失败/回收/冲突、输入使用、图推定、合成示例和未观察建议分开；来源哈希绑定的审核文件 | 提取产品字段不自动升级制备事实。当前真实样本尚未补充独立审核的产品观察 |
| 材料关系 | 已返回记录中产品与输入的完整身份链接、引用和支持状态 | 不把身份链接称为可直接组合的路线；主动共同中间体补查未实现 |
| 九方向排序 | 方法、迁移、反应性、证据、供应、操作、危害、产出、放大分别提供事实/未知与限制；实验限制、参考优先、操作偏好；完整目标获得记录保留与三层展示配额 | 供应、危害、监管、放大资料供应器未接入。官能团差异只是线索，电子/位阻和选择性不作预测 |
| 执行与接口 | 单协调器锁、独立计算子进程、硬超时/取消、总任务/候选/反应/映射等上限；幂等、revision、原子文件快照、固定快照分页、冻结候选重排、中断保留 | 单访问范围、单协调进程；不提供分布式队列/自动故障续接。运行目录暂需人工维护 |
| 内部查看 | 目标输入、状态、三层统计、来源材料、结构与原子高亮、反应变化、九方向解释、取消/重排/导出 | 是内部研究查看页面；不提供反应编辑器或下游模型预测界面 |

操作偏好采用一个明确但尚未校准的初始规则：只在相同方法资格、证据及信息可用分组内，比较温度区间偏离 25°C 的程度和报告时长。缺失信息不填成容易操作；这个偏好不估计实际能耗、选择性或风险。默认参考价值排序不使用这一操作偏好。

## 验证结果

项目自身的锁定环境安装在 `implementation/.venv/`，Python 3.12.12、RDKit 2026.03.2。运行与开发依赖固定于本目录 `uv.lock`。

- 中文交接说明覆盖业务源码、测试、根目录脚本、`reviews/` 和绘图脚本：78 个模块、64 个类、422 个具名函数。检查逐行核对说明并提取独立/行尾注释，避免仅因同一函数里有中文就漏过其他英文段落；工具指令保留原语法。前端函数和事件回调另有中文说明。阅读入口为 [HANDOVER](HANDOVER.md)，并提供[函数索引](FUNCTION_INDEX.md)、[运行架构图](system-architecture.svg)和[核心业务逻辑图](core-business-flow.svg)。
- 自检：`uv run --frozen python scripts/check.py`；中文说明覆盖检查、200 项测试、Ruff、mypy、模块导入边界、契约漂移与 wheel 构建通过。前端异步回归需要 Node.js，本次全部执行，包含六个乱序响应或正常流程场景。
- 已完成[整体审查的 15 类修复](CODE_REVIEW.md)，并在[三轮复审](MULTI_ROUND_REVIEW.md)中新增修复 11 类问题：精确支链立体信息、目标成键/环状态、回放额度与步骤引用、部分审核、异常条件、初始化锁、请求校验和重排版本追溯。当前真实目标试跑使用最新实现哈希；先前各项探针仍绑定其各自已验证的版本。
- [执行层审查](RUNTIME_REVIEW.md)另修复 9 类代码问题，新增 22 项回归：半包通信/启动预算、提交失败、排队取消、SDK 等待、启动资源清理、原子写、快照校验、关闭与重排、生命周期异常清理。测试包括真实半包和 4 MiB 完整消息传输，本轮没有扩充化学规则。
- [数据边界审查](DATA_BOUNDARY_REVIEW.md)补充修复 4 类问题：不完整来源定位错误去重、空结果重排漏校验、快照内容与路径身份错配，以及失败导出发布残缺文件。新增 20 项回归，包括并发导出不覆盖和失败后可重试。
- [执行层补充复核](RUNTIME_REVIEW.md)又修复请求/配置共享可变对象、结果接收期间中断被覆盖两类问题，新增 6 项回归。请求接纳、返回状态和重排输入均使用独立快照，客户端来源配置不随外部对象修改而变化。
- [数据边界补充复核](DATA_BOUNDARY_REVIEW.md)修复非法 JSONL 行的隔离及单个损坏任务阻断启动两类问题，新增 21 项回归。坏状态/快照保持原文件并通过健康接口报告，不影响其他有效任务；真实存储 I/O 错误仍明确阻止启动。
- 结构缓存与实验引用分开：同一结构可共享结构核验标识，返回的见证 ID 则绑定具体反应与材料实例；摘要中保留实际成断键、目标位点、条件和原始目标编号参照。
- 化学回归包括：无环目标、官能团角色、完整 R 范围、对称后过滤、桥连/额外边、同位素氢、目标立体、R 相等、位点并集与联合覆盖、原子顺序、跨页截断、映射异常、共振/真实 H 变化、实际环变化、来源约束回放和整骨架/支链单输入替换。
- 数据与服务回归包括：脏记录隔离、结构绑定名称、冲突来源 ID 隔离、证据不能由产品字段虚构、合成示例不计文献命中、来源审核绑定、预算与摘要不足、源预选失败补查、幂等/认证/固定快照分页、取消/硬超时、协调器锁、重启状态和不重查的重排。
- 真实 TCP HTTP 验收：仅在本机临时端口启动服务，页面/就绪检查/提交/状态/资料包/SVG 均通过；示例返回 5 个材料参考和 2 个替换建议，真实制备命中为 0。验收后已停止临时服务。
- 真实来源接入：只读导出当前源库 5 条记录，经现有字段适配完成结构检索；多组分脏结构单独报告。没有修改源表或索引。
- 真实 PG 常量探针：醇核心 SMARTS 对醇为真、对醚为假，指纹自身距离 0；就绪检查正确发现缺少 `products_mol` GiST。该测试不代表实际索引召回/执行计划验证。
- 本轮修复后的 GiST 实际键列目录查询已在真实来源以只读事务核验；仍缺少所需的 `products_mol` GiST，没有执行全库索引检索。
- Compose 配置检查通过；当前账号无 Docker daemon 访问权限，容器构建、启动与部署效果未验证。GitHub Actions 工作流已写入；本地通过不冒充远端 CI 已运行。

接口补充复核修复 CLI 预览接管任务目录、HTTP 配置受外部修改影响两类问题，新增 4 项反例回归，详见[执行层审查记录](RUNTIME_REVIEW.md)。

结果范围复核修复输入使用检索误报完成、材料关联恰好达到上限误报截断两类问题，新增 8 项回归，详见[执行层审查记录](RUNTIME_REVIEW.md)。

## 真实目标首轮试跑

[目标集合](../evaluation/targets.jsonl)来自已读取的 300 条真实反应样本，用完整产物的结构差异进行有限选样。每个目标分别运行保留原记录与屏蔽全部生成该目标记录两种任务；[完整报告](../evaluation/sample_report.json)记录来源快照、目标哈希、实现/规则哈希、逐目标结果、范围及停止原因。

12 个保留记录任务均找到了目标结构；12 个屏蔽任务均未重新混入这些目标产物记录。部分任务触及反应或输入使用预算，结果明确为部分范围。运行耗时记录在报告中：它测的是已加载 300 条固定样本后的应用流程，存在样本缓存，不能外推为在线端到端延迟或千万级性能。

当前全部方法相关性标签为 `unreviewed`，没有计算方法精确率/召回率，也没有将未审核的产品字段计入真实制备命中。结构自命中与屏蔽隔离验证不能代替化学方法质量评测。该数据集不是独立分子系列/来源分组后的模型泛化评测。

## 剩余发布门槛

1. 对真实目标、方法贡献、失败/冲突及产品观察补充独立审核，评估有用方法召回、排序与单输入迁移的正确性。
2. 源库化学索引就绪后，核对实际执行计划、整侧与具体材料的差异、冷/热查询、宽查询和取消后的后端停止；扩大到真实可用数据规模再给性能指标。
3. 在真实环境验证容器、运行目录保留策略、磁盘上限与故障恢复要求。当前文件存储仅承诺单协调器的内部试用范围。
4. 逐项扩充保护/互变异构体等化学视图、复杂 Markush、共同中间体主动补查及外部资料供应器，保持能力状态和回归用例同步。

这些条目不会使首版检索强制等待用户选择骨架或调用预测模型；缺少能力或证据时，系统自动返回已有参考、图推定及明确未知。
