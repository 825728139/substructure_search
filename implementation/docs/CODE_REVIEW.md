## 真实来源与浏览器集成复核（2026-10-30）

在 `d85eb3d` 基础上继续补查先前只有代码审查或替身测试的路径。

**确认并修复一个前端问题：** 温度控件使用 `type="number"`，但没有声明步长，浏览器默认只接受整数。`25.5°C` 和 `-10.5°C` 都会被浏览器阻止提交，与后端允许浮点温度的契约不一致。修复为 `step="any"`。两个真实浏览器反例修复前均失败，修复后能提交并确认请求中的温度数值正确。

新增 [PostgreSQL 集成测试](../tests/test_postgres_integration.py) 8 项，使用本机 PostgreSQL 18.3 和 RDKit SQL 扩展（`rdkit_version()` 返回 `0.77.0`）：

- 产品及反应物服务端游标逐页枚举，事务实际拒绝写入。
- 真实指纹近邻查询、独立子结构通道，以及组合键/反应 ID 两种详情关联。
- 表锁等待触发真实语句超时，回滚保存点后仍可执行另一家族查询。
- 其他会话更新材料时，本次 Repeatable Read 会话仍使用原结构及对应详情。
- 脏行产生空材料页时不提前结束，多产物行不改变 SQL 行游标的推进口径。
- PostgreSQL 候选、结构核验、详情与数值条件共同生成资料包，产物字段不升级为制备证据。

为校准测试表，仅只读核对了现库两张表的相关字段类型：段落为 `text[]`，温度/压力为 `real`，时长为 `bigint`，详情使用来源组合键。没有读取现库反应内容或修改现库。测试自行创建私有 Unix socket 临时库并清理；这些小样本查询证明适配路径可运行，**不证明生产优化器选择了索引，也不代表千万级性能验收**。

新增 [真实浏览器测试](../tests/test_browser_integration.py) 4 项，使用 Playwright 1.64.1 与本机 Chromium：正/负小数温度提交、12→18 条分页/12 张实际结构图加载/重排与下载快照对应、认证失败后修正令牌再次提交。原有 Node 的六项乱序响应回归仍保留。浏览器测试发现并修正了自身的等待竞态：必须等到 12 张图片真实出现并加载完成，不能把空列表的 `every()` 结果当作图片加载成功。

完整检查 **231 项测试通过、无跳过**，中文说明、静态检查、契约检查及 wheel 构建通过；24 项固定样本评测按当前实现重新运行。手工调试及测试夹具创建的临时服务均已关闭。真实浏览器验证覆盖交互和图片加载，没有执行跨浏览器或像素级视觉回归。
