## 实际效果与仍存在的问题

- 原四目标已核查的方法参考保留：含氮桥环构建、芳位肼基安装、含氧桥环构建、芳基吡唑成环。取代位置、氧化态、选择性及底物迁移仍有缺口。
- 新六目标审查显示，默认前五项中4个目标有明确相关方法，1个只有条件性参考，1个未核实形成方法。后续无环调度改进让条件性参考之外的实际酰胺化方法进入默认前排。
- V05仍有Boc/正丁氧羰基身份混淆；V02有内部矛盾的精确产物记录；V06仍有原文未核实记录排在可靠方法之前。自动规则尚不能替代来源核查。
- 普通目标可能出现SQL超时或预算截断。已有某个表达式的完成状态不等于全库方法检索完成。
- 原子/键覆盖率不代表化学环境等价、路线完成度或成功概率。保留相关结构并不意味着可以直接换一个反应物合成目标。
