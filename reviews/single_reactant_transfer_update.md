# 定向修订：支链和整体骨架的单反应物替换机会

日期：2026-10-25。用户强调：参考产物与目标仅差局部基团时，可能只需调整原反应的一个反应物，既可以改变支链供体，也可以改变母核来源。

此前设计已支持局部连接类比和“参考产物到目标”的真实转化桥接，但未将“直接调整原反应输入”定义为独立候选类型，容易错失高价值的类似物反应。

已修改：

- [主计划](../plan.md)加入模型预测前的有来源约束替换类比。
- [专项规范](../design/single_reactant_transfer.md)定义差异归因、来源实例、原角色保持、替代结构、有限回放、条件支持与推定分账。
- [详细规则](../design/specification.md)第 5.7 节及验收、[连接方法](../design/attachment_methods.md)、证据契约和预算同步更新。
- 新增 [替换流程图](../diagrams/single-reactant-transfer.svg)，总览与连接方法图同步。

验证：本地 RDKit 2026.03.2 的 [7 组人工回放例子](single_reactant_transfer_checks.json)支持支链供体、母核供体、双来源变化、竞争位点、角色不符和错误位点的结构判据。该探针没有实现通用差异归因或真实底物推荐，不验证反应可行性与条件沿用。

主规范新增 8 项设计验收，现为 71 项；七张图渲染、文档链接和 Git 差异检查通过。生成的反应物/转化始终标作推定，不加入已报道制备或连接方法计数。
