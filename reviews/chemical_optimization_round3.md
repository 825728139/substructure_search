# 第三轮化学研究：反应解释、底物份数与手性获得方式

日期：2026-10-23。对象：[当前主设计](../plan.md)。本文件保留第三轮研究依据；2026-10-23 已纳入主设计和流程图。文中的缺口与 35 项案例数指补充前版本，设计纳入不代表检索功能已实现。

## 1. 结论：把已经找到的反应解释准确

前两轮已覆盖结构视图、支链共存、端口、成环、反应方向、原子来源、实验结果与条件关系。本轮不再将它们重复列为缺项，重点细化五类实际会影响化学解释的情况。

| 新增重点 | 当前已有内容 | 仍需明确的判断 |
|---|---|---|
| 映射变化结论的稳定性 | 可靠映射、歧义与未知 | 多个合理原子对应是否会改变新成键结论？ |
| 相同底物的多份参与 | 完整组分集合、重复记录去重 | 同一结构进入产物两次时，如何保留两个分子实例？ |
| 目标手性如何获得 | 立体匹配、ee/dr、目标要求覆盖 | 手性来自底物、新建立，还是拆分富集？ |
| 零重原子键变化的获得记录 | 构筑/修饰/转化标签 | 拆分、富集等有价值记录是否会被误判为无反应？ |
| 实验阶段与分析衍生化 | 一锅、原位、条件和分析证据 | 产物在哪个阶段出现，测量结构是否等于合成目标？ |

这些判断都可以对检索到的原始记录执行，仍在模型预测之前完成。它们细化现有的反应解释与证据模块，不需要增加新的检索层级。

## 2. 原子映射不应只给一个整体“可靠”标签

### 文献支持

原始研究明确讨论了两类问题：不同原子对应可能拥有相同图编辑代价；对某些反应，最少断键的映射也未必正确。文章同时展示了反应式省略重复底物份数时的映射问题。[原始研究](https://www.nature.com/articles/s41467-019-09440-2)

### 本地结构示意

对相同的酸、醇和酯/水结构，可构造两套氧原子对应。两套都表现为一根键断开、一根键形成，但得到的新成键位置不同。去除原子映射编号后的反应物与产物结构完全相同。

该例只证明端点结构和图编辑数量不能唯一决定原子来源，不表示两种机理都适用于某个实际实验，也不指定哪套是具体记录的正确映射。

### 建议细化

将“映射可靠”拆成三个层次：

1. **形式检查通过**：编号唯一、元素/明确同位素相容、没有非法重复对应等；它不代表化学正确。
2. **局部结论稳定**：在已检查的、满足基本约束的候选映射中，目标相关连接的形成/保留结论是否一致。
3. **化学来源支持**：原文、明确转化类别、示踪证据或人工审核是否支持具体对应。

对目标每个关键键分别输出：稳定支持、映射间有争议、来源不足、未评估。不同映射对该键结论一致可以增加稳定性，但不能凭多个算法一致就宣称实验来源得到证明。有限候选枚举的范围和截断状态必须保留。

争议只影响相应局部结论，仍可返回可靠的产物身份、底物和出处。原子编号改变但化学上等价的映射先归并；不要把纯编号差异当成新的构筑策略。

## 3. 同一底物结构，可能有两份进入产物

### 容易出错的位置

当前有完整组分集合和结构去重，却未明确定义反应内部的分子份数。若某缩合或环构筑需要同一个底物的两份分子，按标准化 SMILES 去重会把它们压成一个来源。

本地使用两份乙醛参与一个加成产物的人工映射示意：两份来源结构相同，但有各自的原子实例；一个乙醛只有 3 个重原子，图示产物有 6 个。把来源压成单份后，原子对应与分片覆盖必然失真。此示意没有实验条件，不是可行性验证。

### 建议细化

区分四件事：

- 化合物身份：两份乙醛仍是同一种化合物；
- 反应内分子实例：每份参与结构有独立编号与原子对应；
- 实际投料当量：来自原文，过量使用不等于每份都进入产物；
- 产物原子来源份数：由可靠来源关系或明确记录支持，未知时不硬填。

检索和缓存可按结构去重；展示和反应解释恢复实例份数。三层候选的不同目标位置也不能因来源结构相同而丢失。

原文省略份数时可标“需要核对来源份数”，不能仅为配平就自动复制底物，也不能将未记录副产物或试剂问题一律判为错误反应。

## 4. 产物手性符合目标，不等于本步建立了目标手性

### 文献支持

动力学拆分研究存在通过回收较少反应的一方，获得富集手性起始物的实例。这种记录对目标获得有用，却不是在目标分子上新建其骨架或立体中心。[原始研究](https://www.nature.com/articles/s41467-022-29319-z)

### 建议增加“手性获得方式”

| 标签 | 所需依据 | 给模型的意义 |
|---|---|---|
| 从底物继承 | 输入底物已有对应立体信息，产物关系可确认 | 仍需获得该手性底物，不表示本步解决了来源问题 |
| 本步建立 | 有关结构和实验描述支持从相应前手性结构建立指定结果 | 提供立体构筑参考 |
| 去对称化 | 原始对称/等价位点与反应选择有明确依据 | 为对称前体提供不同的构筑入口 |
| 拆分/富集 | 原文与测量明确说明拆分或富集过程、所取部分 | 提供目标获得方式，不能改写为不对称成键 |
| 构型改变/立体会聚 | 对应结构及实验信息支持该过程 | 与保持、单纯继承分开 |
| 来源未知 | 输入或过程未记录足够信息 | 高 ee 产物本身不能补足缺失依据 |

未知手性的输入 SMILES 不能自动当作外消旋或前手性底物。分子上“新可辨识立体中心”也未必等同于新建该处连接，例如去对称化可能改变等价性；需要结合结构和来源判断。

同时记录 ee/dr 属于目标产物、反应后回收底物还是分析衍生物。若得到的是回收的一方，不能把转化率、回收率和生成产物收率混为同一数值。

## 5. 零重原子键编辑不应导致有用记录被删除

当前变化分析以成键、断键和键型变化为主，可能遗漏只改变立体组成或获得形式的记录。

本地示意中，两种相反构型的 2-丁醇有相同的重原子键集合，但严格立体结构不同。这只说明键编辑检测不能覆盖全部目标变化，不证明存在直接翻转反应。

建议将记录同时归到两个维度：

- **分子图变化**：连接、键型、立体、同位素、组分状态等实际已记录变化；
- **获得操作**：反应制备、拆分/富集、分离/回收、形式转换或操作未知。

经明确拆分获得目标构型的记录，可作为获得目标的先例，但不增加核心构筑或新成键计数。普通回收未改变的起始物不能当成“从更简单前体制备成功”；若回收部分的组成得到有据的富集，单独标注其贡献。

没有重原子键编辑也不能自动分类为拆分；没有原文依据时只返回变化未知或结构未变。

## 6. 反应、后处理、分析衍生化需要按阶段区分

### 文献支持

一项不对称反应筛选研究将产物衍生化为非对映异构体，再用离子淌度质谱分析比例。这证明测量所用的衍生物结构可以不同于原反应产物。[原始研究](https://www.nature.com/articles/s41467-023-42446-5)

另有原始研究明确通过后续水解/后处理得到游离胺；仅保留箭头上主要转化信息可能遗漏最终获得形式相关的步骤。[原始研究摘要](https://www.sciencedirect.com/science/article/pii/S0040403909021583)

### 建议细化阶段关系

对来源明确的阶段分别保留：

```text
实际投入物
  → 反应阶段的已观察结构或未知状态
  → 有化学变化的淬灭/后处理（如有来源支持）
  → 分离获得的结构
  → 取样后的分析衍生物（如有）
```

这不是要求系统从净反应自动推断微观机理。只有来源明确的阶段才建立关系；缺失阶段保持未知。

需要避免的误读：

- 将后处理水解所得产物归因于前面催化步骤已直接生成；
- 将分析衍生化所用试剂和催化剂当成主合成反应的条件；
- 将衍生物的测量结果直接挂到另一结构而不保留关联依据；
- 将用于捕获或分析的衍生物默认当作已经分离制得的主目标；
- 将原位不可分离结构默认为可以跨实验自由使用的中间体。

分析衍生物本身也是真实化学结构，若有明确制备证据且恰好符合另一个查询，可以作为它自身的参考；关键是正确关联结构、实验阶段和证据，而非一概删除。

## 7. 建议加入的验收案例

| 案例 | 应有结果 |
|---|---|
| 同一反应结构的两套映射产生不同新成键 | 只确定无争议的局部结论，争议键不计确定构筑证据 |
| 两个映射只交换化学等价编号 | 归并等价关系，不虚增构筑方式 |
| 同一底物两份进入一个产物 | 化合物身份可去重，分子实例及原子来源份数保留 |
| 原文使用两当量，但只一份提供产物原子 | 投料当量与来源份数分别记录 |
| 高 ee 产物继承高 ee 底物 | 标继承，不能声称本步建立了手性 |
| 动力学拆分得到富集的回收起始物 | 标拆分/富集获得，保留对应 ee 和回收信息，不计新成键 |
| 相反构型但零重原子键变化 | 立体差异仍被识别，不能作为完全相同结构删除 |
| 原结构经后处理变为分离产物 | 条件与阶段保持对应，不编造未观察中间体 |
| 取样后衍生化用于 ee 分析 | 测量结构、原产物与分析过程分别对应，不误归到主反应 |

## 8. 优先级与验证范围

优先补映射结论稳定性、底物实例份数和手性获得方式，它们直接影响当前已设计的构筑证据、原子来源与参考排序。实验阶段和零键编辑的获得记录随后一起补到证据整理模块。

当前已有 35 项主设计验收案例；本轮建议将上述针对性案例纳入实际实现时的基准集，先测出会造成结论错误的分支，再决定是否需要更多泛化规则。尚未有真实检索引擎或全量样本，不能把理论优化数量当作实测质量提升。

新增 [3 组图结构检查](mapping_and_stereo_checks.json)及其[脚本](check_mapping_and_stereo.py)使用 RDKit 2026.03.2，分别检查映射歧义、同结构多份实例、零重原子编辑下的立体差异。均为明确标记的人工示意，不是来源实验、实验方案或反应可行性验证。

文献访问范围：原子映射、动力学拆分和分析衍生化研究读取相关正文；后处理游离胺研究仅使用公开检索摘要，未阅读全文或补充实验。以上模块建议是根据这些现象与当前设计推导，不表示文献直接验证了本系统。
