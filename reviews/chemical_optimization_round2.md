# 第二轮化学研究：从结构相关走向有用的合成参考

日期：2026-10-23。评审对象：[已补充的三层前置检索设计](../plan.md)。本文件保留第二轮研究依据；2026-10-23 已纳入主设计和流程图。文中缺口描述指补充前版本，设计纳入不代表检索功能已实现。

## 1. 本轮结论与优先级

继续保持“整体/核心/分片检索 → 参考反应整理 → 模型预测”的执行顺序。上一轮已覆盖保护形式、互变异构、端口、成环、支链共存、立体和多维覆盖，本轮不将这些重复作为新发现。

接下来最有价值的改进是更准确地回答：**哪条命中真正解释目标的构筑问题，哪条只是结构相近？**

| 建议 | 相比当前设计新增的具体能力 | 优先级 |
|---|---|---|
| 按反应位置比较电子/位阻环境 | 将“官能团类似”进一步细化为位置、共轭路径和局部空间约束 | 首批 |
| 官能团差异加方向及桥接证据 | 区分结构相关、已有正向转化、仅有反向记录 | 首批 |
| 按实际原子来源和构筑方式保留多样性 | 同一酰胺等产物类型可能来自不同切断及多组分构筑 | 首批 |
| 区分观察、分离、失败和预期产物 | 防止“有产物字段”直接变成“已制备成功” | 首批 |
| 识别同源中间体及真实步骤关系 | 给头尾互补增加来自同一实际中间体的资料线索 | 第二批 |
| 选择性依赖条件成为参考的一部分 | 标记关键催化、光/电、反应器等差异，不只返回条件自由文本 | 第二批 |
| 骨架嵌入方式与关键局部结构优先级 | 明确稠合、桥接及局部高价值构筑问题，改善大而常见骨架主导排名 | 第二批 |
| 同位素与真实骨架编辑关系 | 处理特定目标和少见但有文献依据的拓扑变化 | 范围扩展 |

这里的优先级是设计判断，尚无真实查询集的收益测量。建议先用少量专家标注的目标比较有无这些特征的排序，不直接引入未校准的“合成成功分”。

## 2. 端口一致，电子与位阻环境仍可能完全不同

### 现有缺口

当前已记录真实端基、官能团及邻接环境，但尚未规定哪些环境信息对某类参考反应更重要。完全相同的 C–Cl 端口，不代表对应芳环具有相同反应行为；泛化后共同出现的 N、O 也可能处于不同共轭或配位位置。

### 研究依据与本地检查

关于芳香亲核取代的原始研究，将反应位置及邻/对位的静电环境用于描述反应性，也讨论了对某些底物的适用边界。这支持“只比较离去基团和很小半径邻域是不够的”，但不意味着可把该反应类别的规律直接用于其他转化。[研究原文](https://pubs.rsc.org/en/content/articlehtml/2022/sc/d2sc04041g)

本地测试对硝基和间硝基氯苯：两者都匹配同一个氯苯子图，C–Cl 位点的一阶图邻域相同，但硝基相对位置不同。本测试只证明结构描述丢失了位置差异，没有计算两者反应速率。

### 建议

对每条已有参考反应，在已知反应位置周围增加可解释的环境描述：

- 所在芳环/杂环类型，杂原子与反应位置的相对关系；
- 共轭路径上的吸/供电子结构特征及其位置；
- 邻位取代、支化程度、环刚性等位阻相关结构线索；
- 可参与配位或定向的结构及与反应中心的关系；
- 目标与参考中额外出现或缺失的相关特征。

按已识别的参考转化类别选择特征，不设一个对所有反应通用的“电子相似度”。目标没有指定转化时，这些比较依附于检索到的实际反应，而不是要求模型先提出反应。初期用结构规则与差异说明；计算描述符或三维分析仅作小规模候选的后续增强，不用作未经验证的全局硬过滤。

## 3. “局部修饰”需要方向和已有桥接证据

### 现有缺口

保护形式和氧化态分支已经能够召回相关分子，但“参考分子与目标相差一个羰基/羟基”仍没有回答能否沿需要的方向变化。

例如目标是某醇，参考是对应酮：只有从醇到酮的氧化记录，不是从该酮制得该醇的记录。结构关系可以是对称的，反应证据必须有方向。

### 建议

将每个第一层差异标注为以下状态：

1. **实际桥接**：有明确记录连接该参考分子与目标结构，方向、其他组分和立体要求均有出处；
2. **同类差异的正向先例**：其他相近底物上有该方向变化，标为类比；
3. **仅反向记录**：方向相反，不能转写成正向先例；
4. **结构差异线索**：尚无相应反应支持；
5. **信息不完整**：无法可靠判断具体方向或身份。

对少量优先参考可补查一至两条**已经记录的反应边**，保持严格的中间体身份和方向。相近而不相同的中间体不能直接串起来；没有文献边时不生成假反应，也不把此过程扩展成自动路线预测。

排序增加“相关形式 → 需要的方向 → 有多少真实支持”三个维度。结构变化小、步骤少及实验容易是不同概念。

## 4. 同一产物官能团，可以有不同原子来源和战略切断

### 研究依据

一项原始研究报道通过异腈、卤代烷和水形成酰胺，提供区别于常规酰胺偶联的构筑方式，关键 C–C 形成与后续水解共同产生酰胺产物。[原始研究](https://www.nature.com/articles/s41467-023-41253-2)

这不是说现有产物检索必然漏掉该反应：若产物结构匹配，当前方案可以找到它。缺口在于候选切片、结果聚类和参考配额若只按“酰胺 → C–N 切断”组织，会把这种记录的价值解释错或挤出结果。

### 建议

在已核验的命中反应中补充：

- 目标相关原子分别来自哪个实际反应组分；
- 哪些目标键是新形成，哪些本来已存在但键型改变；
- 构筑是否涉及两组分、三组分或更多组分；
- 是否存在供给一个原子或小单元、但在产物中很关键的组分；
- 是否有无法确定的来源、缺失反应物或非唯一映射。

按**构筑方式和来源分区**保留代表实例，不能仅按产物官能团名称或一个新成键标签去重。多组分记录作为完整组合返回，不拆成若干彼此独立、貌似成功的两组分反应。

本轮的原子映射示意检查展示了一个酰胺产物中 N–C 连接原已存在，而新形成的是另一条 C–C 和 C–O 连接。该示意是人为构造的图验证，不是上述论文的具体实验记录，不构成实验可行性判断。

## 5. “产物出现”需要区分实际取得与分析/预期状态

### 现有缺口

计划要求“真实产物及制备记录”，但未具体定义判断标准。真实资料可能记录计划产物、观察产物、混合物组分、痕量分析信号，以及分离并表征的产物。它们不能共用一个没有等级的“制备成功”。

公开反应记录规范也明确区分观察/预期产物，并将身份、收率、纯度和选择性等分析与产品关联。[资料语义参考](https://docs.open-reaction-database.org/en/stable/schema.html#outcomes)

### 建议

给每个实例保留：

- 文献明确报告制得；是否分离与表征分别记录；
- 分析检测到或定量检测到；保留检测类型及身份确认程度；
- 仅列为预期产物，未观察到；
- 明确失败、分解、形成其他异构体或其他产物；
- 原文信息不足。

不要设置一个未经依据的统一收率门槛，也不要把收率缺失视为零或失败。分析存在仍有参考价值，但应与可分离制备证据分组。明确未观察到的目标不增加正向制备命中。

如果资料有失败底物、区域/化学选择性副产物或相同底物的不同结果，应与对应条件一起返回。失败仅说明记录条件下的观察，不能永久封禁该骨架或反应类型；没有失败记录更不能推导成功概率。

## 6. 头尾互补可以增加“共同中间体”的真实线索

### 与已有支链矩阵的区别

当前矩阵比较产品位点与引入/保留证据，但尚未系统地组织这些产品是否来自同一个实际前体。

两个类似物来自同一个有多个可衍生位点的中间体，通常能给模型提供比两个无关末端产物更具体的构筑入口。这里的“更具体”指证据关系，不预先保证两条衍生化可以同时完成。

### 建议

在已召回实例中，按完整底物身份、保护状态和实际位点把它们组织为小的文献关系图：

```text
已报道的共同中间体
  ├─ 真实反应甲 → 带目标头部的参考产物
  └─ 真实反应乙 → 带目标尾部的参考产物
```

分别标注两步是在不同位点使用、竞争同一位点，还是因对称性无法区分。共同底物必须是同一真实结构；只共享一个核心不能算同一中间体。

若另有“先引入头部后再引入尾部”的真实步骤，可附已知顺序；若没有，显示仅存在分支参考。保护形式不同的中间体需要实际关系说明，不能因去保护视图一致就把文献节点合并。

该资料图只组织已有记录，依然在模型预测前生成，不负责补全缺失路线。

## 7. 条件可能改变选择性，应标记其必要依赖

当前已保留条件，但它们对参考价值的影响不能只当作附属文字。

原始研究中，同类 N-杂芳环羧化在不同电解装置下呈现不同位点选择性。这是“结构相近且转化名称相同，关键条件仍可能改变结果”的具体证据。[原始研究](https://www.nature.com/articles/s41586-022-05667-0)

建议增加参考实例的条件依赖摘要：关键催化剂/配体、活化或预处理方式、光照或电化学要求、反应器类型、来源明确强调的浓度/加料等因素。只依据来源赋予“已报道依赖”；资料没有比较实验时，不能从一次使用推断某因素必不可少。

特别区分：未报道所需条件、无法判断依赖、已有相互矛盾但条件不同的记录。同一分子在不同条件下的不同选择性结果都应保留，不能简单按分子和净反应去重后只留最高收率。

检索阶段不因此预测新条件，而是让模型知道哪些条件和选择性线索不能被随意丢掉。

## 8. 骨架嵌入方式与局部关键结构，值得单独排序

### 8.1 多点连接还应区别普通跨链和额外成环

现设计已经要求多点连接整体比较，本轮建议再明确它们的关系类型。本地实测同一个苯环查询：

- 甲苯外部甲基与核心只有一个边界连接；
- 联苯外部苯环与核心也只有一个边界连接；
- 萘中核心外的四个碳通过两个边界连接到该苯环，并构成额外稠合环。

三者均能子图命中，但后一种不应描述为普通“头部/尾部换一下”。可记录核心外连通部分的接触原子数、是否参与闭环、附加路径和稠合/螺接/桥接特征；不能仅凭两个接触点就认定一切都是稠合环。

这类记录可以作为骨架构筑参考保留，同时标出额外拓扑差异，不因原子覆盖高而自动列为简单修饰参考。

### 8.2 查询预算需关注构筑问题，而不仅是结构大小

大的常见芳环片段容易获得很多命中，较小的全碳季碳中心、连续立体中心、螺中心或桥头连接可能更需要专门参考。

建议按可确定的结构特征设有限查询配额，分别展示这些位置是否有形成或立体控制证据。不要把某类结构自动判为困难或不可合成；优先级最终仍需用实际任务校准。

该优化复用现有的多维覆盖统计，但改变候选预算分配，使“最需要解释的位置”不会被大量普通骨架结果淹没。

## 9. 范围扩展：同位素与有出处的骨架编辑

### 9.1 同位素标记

目前设计讨论电荷和手性，但未明确目标的同位素要求。目标带有 13C、2H 等标记时，要记录同位素、指定位置及是否有相应标记来源证据；不能只靠重原子覆盖率判定充分。

本地测试中，带明确 13C 的查询不匹配未标记乙醇，未指定同位素的查询却能匹配标记结构。因此核心提取、标准化、去重和原子来源判断都需要保留用户明确的标记要求。交换位点上的氘还需单独标记来源及信息缺口，不能把有机骨架一致等同于标记稳定。

不处理标记目标的首版也可以明确声明范围，避免静默去掉同位素后输出严格命中。

### 9.2 骨架编辑

当前化学相关视图主要保持主连接拓扑，而已有原始研究展示了改变骨架连接的原子删除等方式。[氮删除研究](https://www.nature.com/articles/s41586-021-03448-9)

产物匹配时，现有系统本就可能找到这样的记录；真正的额外能力是对部分未严格命中的前体关系作有依据的拓扑变化检索。

建议列为后续低配额扩展，只允许来自真实记录并经过审阅的局部关系，保留反应方向、适用环境和准确出处。不要任意增删原子，也不要把药物设计中的生物电子等排替换直接当作合成可转化关系。

## 10. 建议的落地顺序

优先补四项：反应位置的电子/位阻环境、结构差异的方向证据、多组分原子来源、产物结果证据等级。它们直接影响参考排序和“有多少可用先例”的解释。

随后增加共同中间体关系、关键条件依赖、骨架嵌入方式及局部关键结构预算。明确有标记化合物需求时提前处理同位素；骨架编辑作为后续扩展，避免首版泛化过度。

建议新增验收样例：

| 例子 | 需要辨别 |
|---|---|
| 相同氯苯局部端口，不同硝基相对位置 | 小半径环境相同不表示反应环境完整相同 |
| 目标醇与参考酮，只有反向氧化记录 | 结构相关不等于已有所需方向的证据 |
| 酰胺来自不同构筑方式 | 官能团相同不等于同一新成键或同一底物分区 |
| 预期产物、痕量分析、明确分离产物 | 不能用同一无分级成功标签计数 |
| 两个产物共享真实前体，或者仅共享核心 | 共同中间体关系必须有完整身份支持 |
| 同结构不同反应器条件导致不同位点结果 | 保留条件关联，不用单条高收率覆盖所有记录 |
| 苯环嵌于联苯或萘 | 单点外接与多点成环嵌入分别解释 |
| 明确同位素目标与无标记参考 | 结构召回可保留，严格目标要求不能被忽略 |

## 11. 本轮证据与局限

文献用于支持具体化学现象；将它们转为上述模块和排序要求是本轮设计推导。没有把单篇反应研究的适用范围推广为所有底物通用规律。

新增 4 组本地结构检查使用 RDKit 2026.03.2：端口局部环境与远端位点差异、单点/多点骨架嵌入、人工示意中的原子来源与实际变化、同位素查询方向。见 [脚本](check_reaction_relevance.py)和[结果](reaction_relevance_checks.json)。不包含反应速率、条件优化或真实数据召回率验证。

访问范围：SNAr 研究使用可访问摘要与全文检索片段；异腈酰胺研究读取正文；电化学选择性与氮删除研究依据摘要；反应结果状态参考公开文档。没有声称审阅所有补充实验。
