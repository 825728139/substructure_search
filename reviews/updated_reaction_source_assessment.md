# 修正后的两个反应表：首版接入复核

日期：2026-10-28。当前处于全量入库过程。本次只读检查 `reaction.reactions`、`reaction.reaction_details` 的字段、注释、约束与索引，按主键读取较早 120 条和较新 180 条，总计 300 条；另核对两条记录的原文。没有修改数据库或导入作业。

**结论：修正后的字段已经足够作为首版“子结构检索找反应先例”的来源契约，可以据此推进只读适配器和检索分析模块。完整映射、原始证据对象、材料详情与角色来源都有承载位置，不需要为了开始实现继续扩充核心表。**

前一份审查的 427 条是实验入库批次，不能代表全量覆盖率。此次样本同样不是随机样本，以下数字只用于核对字段和表示，不推算全库质量比例或最终规模。

## 1. 本次关键修正已经解决的接入问题

| 修正 | 实际字段与行为 | 对检索系统的作用 |
|---|---|---|
| 完整原子映射独立保存 | `reactions.mapped_reaction_smiles`，与无映射的 `reaction_smiles` 分开 | 可从已存来源对应计算实际键变化、产物原子供体和目标连接位置 |
| 原始抽取信息可追溯 | `reaction_details.raw_reaction` 保留原始反应 JSON | 不丢失原字段类型、缺失/null/空串和额外信息；可回看原提取结果 |
| 完整映射审核依据可读取 | `reaction_details.aam_result` 含原反应、来源文件与下标、多个映射器结果、审查和评分记录 | 支持逐项质量解释和复核，避免只看一个总分 |
| 五类材料改成具名 JSON 对象 | products/reactants/reagents/catalysts/solvents 均为 JSONB 数组 | 不再依赖固定的 8/9 列位置；名称、用量、结构、原文提示等字段可直接解析 |
| 供体角色修正保留过程 | `role_resolution` 记录原角色、原始序号、目标序号、贡献原子 map 和规则版本 | 试剂、催化剂或溶剂中的原子供体可进入底物分析，并能追溯原始抽取角色 |

分工明确：`reactions` 提供检索和筛选字段；命中后关联 `reaction_details`，获取材料、来源及映射审核细节，再读取原文证据。粗召回阶段无需每次传输完整 `aam_result`。

对目标母核—支链的贡献、Markush R 位点分配、候选迁移以及最终排名，仍由检索系统根据当前目标计算，不需要提前成为固定来源字段。

## 4. 作为接入约定保留的几点

### 条件和分类允许未知，不阻塞参考检索

样本的温度、时间、压力文本及数值仍为空，且 `raw_reaction` 对应值也为空/缺失。两条原文抽查包含低温、升至室温、过夜等信息，故当前这部分缺口至少已存在于保存的原始提取结果中；不能继续仅根据旧试验批次认定是详情表入库丢字段。

后续可以从上游提取结果或证据补充。现在允许先返回结构、底物、实际变化和原文参考，条件显示未知。源原文有条件而抽取对象为空时，不把它解释为常温、简单或安全。`reaction_class` 在本样本中也全部为空，先根据映射变化建立目标贡献标签，具体类别后续逐步补齐。

### 明确区分入库策略、上游审核状态与参考价值

当前字段说明和导入日志记录门槛为 `final_score >= 5`，分数类型已经改为 integer。本样本所有记录的主表分数与 `aam_result.final_score` 一致；分数范围为 6–22。

样本中 24 条 `aam_result.status=filtered`，对应其内部历史策略 `uniform_threshold=12`；当前入库门槛是 5。两者是不同策略，不能简单将这些状态差异认定为导入错误，也不能把“已经入库”解释为“所有审核通过”。内层 `aam_filter.score.classification` 还保留了 38 条 review，不能混用不同层级的结果。

读取适配器应保留导入版本/门槛、最终分数、源审核状态与失败原因。低分记录可保留参考检索资格，涉及确定的成键依据、模板迁移与单底物替换时再施加相应质量要求；总分不直接作为目标合成成功率或最终参考排名。

例如抽查记录 `id=106451`：来源提取将公式名称关联到了结构差异很大的产物，AAM 仍能形成形式上完整的对应；内部审核为 filtered、分数 9，键变化审查记录了大量变化。结合原文需要再核查产品结构与实验归属。这个例子说明应使用已保存的审核/来源信息分层展示，而不要求所有此类候选都在结构召回之前消失。

### 入库结束或开始提供检索前，确认索引与参数

14:28 左右的目录检查只看到主键和来源唯一键索引，未看到上一批次的 mol/fp GiST 索引。这可能是批量入库阶段的安排，本次未检查导入作业配置，不能据此判断遗漏。首次性能验收前应确认结构索引已建好、统计信息可用，再测典型查询计划；本次没有在正在入库的全表上执行结构扫描或建设索引。

样本存储指纹为 2048 位，新连接默认仍为 512 位。读取适配器显式对齐 Morgan 半径、位数及版本，作为连接初始化约定即可；不需要因此改变数据表结构。

### 保留完整审计信息，返回时按需加载

`raw_reaction` 用于保留原值；角色数组和 `role_resolution` 用于呈现可追溯的整理结果。不要把映射推断的角色当作已经由实验机理证明的角色，也不要将配平重数换算成实测当量。

这次完整的 300 条抽查导出约 10.4 MB，包含嵌套审核对象。候选列表先取轻量标识与结构，精排候选再批量取详情和证据，避免每次宽召回反复传输全部审核对象。
