# 四个用户目标：核心业务迭代第一轮

目标来自用户提供的 `implementation/src/reaction_reference/test` 文本，原文件没有改动。归档输入见 [targets.json](targets.json)，[逐条实际分子图和判断](index.html)展示本轮前五名。**本轮有代码进展，但没有达到四个目标都获得可直接迁移的关键合成先例，整体目标仍在继续。**

## 先明确化学预期，再判断结果

后续复测使用[逐目标的化学预期与审阅问题](chemical_expectations.md)，明确区分“有局部参考价值”和“已可直接迁移”，不要求每条先例独立解决完整合成。

| 目标 | 最需要找到的证据 | 不能替代它的命中 |
|---|---|---|
| U1 | 含氮双环[3.1.1]骨架构建，同时面对目标取代、环外双键和立体关系 | 普通酯水解、只带吡唑的任意改造，或只有类似桥环却没有构建依据 |
| U2 | 同类N-丁基萘酰亚胺芳位的肼基安装，保留N-N和酰亚胺 | 其他胺取代只能提示亲电芳位；不证明肼相容性，也不能把酰亚胺破坏算目标合成 |
| U3 | 带酰基吡唑/芳基取代的氧杂双环[2.1.1]核心构建 | 普通酰基吡唑合成只能作为把手参考，不能当作核心已经解决 |
| U4 | 芳基肼与适当二羰基构建所需N-芳基吡唑，核对3/5位区域关系和磺酰胺保留 | 相似吡唑上的任意保护、长侧链修饰或不同区域异构体 |

这些是我阅读目标结构后的审阅预期，不是写入程序的“命中即有用”规则。业务代码没有四个SMILES、特定专利ID或人工标签的白名单。

外部原始文献进一步支持这些预期，但**不计入数据库召回成果**：

- U1更贴近的方法族包括BCB与异腈生成取代3-氮杂双环[3.1.1]庚烷；出版者摘要明确该骨架构建，而非普通吡唑修饰。具体到用户双酯、双键和立体结构，仍须核对底物范围/补充信息，不能仅凭标题声称精确目标已报道。[原论文](https://onlinelibrary.wiley.com/doi/abs/10.1002/anie.202402730)
- U3有BF3催化醛与带酰基吡唑的BCB构建氧杂双环[2.1.1]己烷的原始论文。这比当前库内的普通醇闭环更贴近目标反应端；本轮读到出版者摘要，补充PDF访问失败，未据此认证目标取代与异构体。[原论文](https://onlinelibrary.wiley.com/doi/abs/10.1002/anie.202305043)
- U2的肼基萘酰亚胺在原始论文中有制备报道，明确涉及肼及后续丁胺的反应；需要检查取代位置和实际母核，不应把任意二胺取代当作肼的已验证替代。[原研究论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9402912/)

后续进展见[第二轮：分片近邻与新增炔酮成环先例](iteration2/report.md)。

## 基线问题与本轮修改

原代码在默认40任务预算下，早期查询一页取100组，少数家族可先吃完详情/分析额度；相似候选池还没有先按当前家族必要核心过滤。没有查到有用结果不能马上解释为库中不存在相关骨架。

本轮只做通用核心检索/排序改动：

1. 在线PostgreSQL页大小优先为2，与用户页上限取较小值，候选沿原游标继续，不丢弃后续页。固定样本显式穷尽仍保留原页大小。
2. 在最多512条近邻池中先做当前核心SMARTS必要条件过滤，避免每个家族都核验同一批无关结构；完整Markush核验仍执行。
3. 每个整体/核心家族最多补入两个“产物含该核心、已知反应物不含同一核心”的索引候选，与近邻交替处理；不是猜测目标断键，也不证明成环机制或可迁移性。未知反应物不当成核心变化证据。该粗图优先依据使用去重表索引，后续全部事实仍来自已绑定的实际合格来源。
4. 近邻池没有当前核心时，立即尝试既有独立子结构通道；仍受SQL超时、任务、反应和候选预算限制。
5. 未经实验来源支持的方法标签与结构线索放在同一资格层，再比较同一见证的两侧重原子覆盖，避免“图推定的局部方法”先验压过更相关的稀有骨架。已报告获得/使用证据的优先级不变，结构覆盖不升级成化学可行性证明。

所有数据库来源仍要求组和实际实验分数≥12。没有加入温度、产率或危险物默认预筛，没有修改数据库数据。

## 实际观察

- U1现在可返回并把3153963桥环构建线索排到前面。在线原专利例15(b)核实了二烯酰亚胺光反应生成相近氮桥环二酮；但目标的氧化态、N取代、酯/双键和立体要求不同，**只能算骨架方法线索，不能说完整目标合成已解决**。[US4677129A](https://patents.google.com/patent/US4677129A/en)
- U2仍主要返回同母核二胺取代；2148857的原文确有76%，但肼的N-N保留及酰亚胺相容性未被这条证明。另有两条“无取代萘酰亚胺”与原文的明确N侧链/芳环取代不符，已判为来源错误，不计有用。
- U3现在第一名10210576有原文支持的I2促醇/亚甲基环丁烷闭合成氧桥环。但其碘甲基、二甲基、甲酯与目标双芳基/酰基吡唑布局不同，**尚不足以直接迁移**。2030567原文是替换使用已制备桥环胺，抽取漏了替换，不能当成凭空构建桥环的成功例。
- U4找到了真正的芳基肼—1,3二羰基吡唑成环，2192223原文报告53%，保留磺酰胺并具有明确N-芳基和3/5位连接关系；2144174也有对应缩合路线描述。来源CHF2/CF3到目标CH3及芳基取代变化仍需核查区域选择性，不宣称直接保证目标成功。

## 验证和后续缺口

完整本地检查484项测试通过、无跳过，含60项真实临时PostgreSQL回归；中文说明、Ruff、mypy、契约和wheel构建通过。新增测试核对核心过滤在分页之前、池外线索保留且不重复/不混入低分记录、在线家族轮转、固定样本穷尽，以及真实匹配反例中未证实方法标签不能压过更完整骨架。数据库测试只允许连接本机私有临时库。

这组分子四个精确合格产物探针均未命中。针对少量核心的诊断与当前检索未发现某条方法，不证明全库绝对不存在；更不能把外部论文当作程序已经找到的反应。

后续仍需解决：U2肼基安装在当前数据库内的直接证据；U1/U3与目标取代布局更接近的骨架构建；前排残留的来源误解析与弱局部线索。不能靠继续提升某个结构分数，将这些缺口改写成已成功。

原始输入文件未改动。`targets.json`是测试快照，`baseline/`和`iteration1-final/`保存实际计时，`chemical_review.json`保存逐条化学判断。完整资料包与原文留在本机`.cache/core-iteration-2026-11-01/`。`run_targets.py`只读复测，连接通过`RR_BENCH_DSN`环境变量提供，输出目录使用`RR_BENCH_OUTPUT`；不要向仓库写入密码。

```bash
RR_BENCH_TABLE=reaction_v3 RR_BENCH_OUTPUT=/tmp/rr-user-four-repeat \
  implementation/.venv/bin/python reviews/core_iteration_2026_11_01/run_targets.py
```
