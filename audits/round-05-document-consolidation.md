# 第 5 轮：单一现行设计与可读实施计划

发现：多轮补充使主计划超过 800 行，读者很难分清目标、规则、接口、试验事实与未实现要求。继续追加段落会增加跨章节漂移的风险。

修订：主计划收敛为目标、三层职责、流程、规则入口、输出、实施、验证和历史。完整原有化学条款迁入 [详细规范](../design/specification.md)，保留章节编号并修正所有文件相对链接。证据和调度契约继续独立，作为同一设计的明确实施约定，不保留竞争性的旧计划副本。

图示修订：总览增加具体目标/查询编译入口；化学召回图强调逐视图谓词与组分实例复核。其余化学解释流程延续已审查内容。

验证：原详细章节、47 个原有化学验收案例和本次补充均保留；文档链接、交叉章节引用、五张图渲染和 Git 空白检查通过。重排不代表新增功能已实现。

剩余：实际工具正确性与数据支持仍按评测门槛验证，不能因为文档更清晰而放宽证据要求。
