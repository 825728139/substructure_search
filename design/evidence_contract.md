# 参考实例与计数契约

本文件规定模型预测前参考包的语义，不规定数据存储。详细化学规则见 [主规划](../plan.md)。本契约没有实现证据抽取器。

## 每个结论必须有指向具体事实的依据

```text
参考实例
  candidate_id / family_id / view_id / target_occurrence_id
  fixed_query_features / R_site_constraints / joint_constraints
  concrete_R_assignments / observed_joint_combination / matching_completeness
  structure_level / source_reaction_topology_assessment / actual_reaction_direction
  source_record_id / experiment_id / component_instance_id
  actual_structure / original_role / material_state / stage_id
  matched_target_atoms_and_bonds / view_relation
  result_observations[]
  reaction_class / class_basis / target_attachment_id
  core_and_branch_matches / boundary_event / reactant_roles
  attachment_method_assessment / applicability_gaps
  chemical_change_claims[]
  obtainment_claims[]
  source_locations[]
  unresolved_fields[]
  ranking_profile / reference_rank / lab_fit_state
  explicit_constraints / ranking_reasons / tradeoffs
  material_identity_and_hazard_sources / operation_stage_requirements
```

每项 claim 包括类型、目标位置、支持的原文/测量、依赖的结构对应、支持层级与适用范围。原子映射是推断依据之一，不替代观察证据；虚拟视图不充当 actual_structure。缺失为未知，不能默认成功、失败或零收率。

直接目标参考区区分 `exact_record_identity` 与 `target_requirements_satisfied`：后者允许来源在目标未约束的立体位置有明确取值，但仍需完整图及实际结果见证。它不表示两个来源身份可合并，也不证明某个未要求的样品组成。相关视图命中和未核实结果不能进入这两类阳性结论。

source_record 标识来源资料，experiment 区分真实实验，component_instance 区分同一实验中的分子实例。相同文献在不同抽取记录中重复出现，不变成独立实验。身份或阶段无法可靠区分时，保留可能重复标记，不伪造确定的独立来源数。

映射/配平产生的输入副本使用 `mapping_copy_id`；其与真实材料实例的联系附归属依据和状态，不默认一一对应，也不增加投料量、实验数或已观察来源份数。多个副本中的原子编号可参与图分析，真实来源结论仍需有据材料对应。

原文“按例 N/通法 A 制备”建立的是操作引用关系，不自动建立新的反应步骤边。仅在文档、例号及适用条款可定位时引用步骤；本例明确替换的底物、用量和条件覆盖相应条款，并保留两处出处。通法中的示例收率、产物身份、ee/dr 和成功结论不能转移给本例；当前结果仍需当前实验的报告。引用歧义、循环或预算不足时保留未解析引用，不让摘要自行补全。这里的继承规则属于本系统设计；输入、条件、结果及出处分别记录的依据见 [ORD 数据语义](https://docs.open-reaction-database.org/en/stable/schema.html#outcomes)。

引用步骤中的绝对投料量也不能直接复制到不同规模或不同底物的实例。须按原文明确的变量、当量或本例数量绑定；没有足够依据时保留步骤描述及数量未知。

## 四个正交维度

1. 结构关系：严格、扩展、无合格匹配、未评估。
2. 实际结果：报告制得、分析观察、拆分富集、普通回收、失败/未观察、未知或冲突。
3. 化学贡献：新成键、键型改变、保留、立体建立/继承/富集、其他或未知；各自附证据。
4. 执行状态：未开始、执行中、完整完成、截断/超时/失败。

“任务完成但证据不足”不等于“化学失败”，也不等于“任务仍在运行”。“已找到一条有据记录”不等于“总数已完整”。

## 合格见证与计数

- 制备命中：存在身份、实际产品结果和阶段均可对应的化学制备见证；单靠产品字段或预期结构不成立。
- 获得命中：制备命中与有据拆分/富集等获得见证的并集。普通回收未变化起始物不增加获得命中。
- 使用命中：底物确实投入/参与的见证，包含失败尝试；不能自动增加连接成功计数。
- 分析观察：与指定结构有明确分析关联的见证。身份不明确的峰只保留候选观察，不能声称指定异构体命中。

上述状态必须绑定同一 `subject` 的具体结构/材料身份和实验角色。`A → B` 证明 B 被制得时，并不证明 B 曾作为输入使用；A 的投入证据不能转移到 B。B 只有在另一条有据投入记录或本条明确的对应输入中，才同时获得使用见证。混合物投入也不能无依据升级为某一纯化材料的投入。各维度按自己的见证计数，`preparation_hit=true` 不推导 `use_hit=true`。

当一个候选有制备见证时，不论其他独立实验是否失败，它都可显示至少一个制备命中，同时保留失败条件。相反，同一个实验的同一结果存在未解决的相互矛盾陈述时，不能只挑阳性陈述作为合格见证。

预期产物与后续未观察到不是同一时间点的事实冲突。不同阶段、不同取样部分及更新的测量要保留时间/阶段关联；只有指向同一事实而互相不相容的陈述才标为冲突。

副产物按自己的实际结果和查询关系判定，可以成为它自身的制备见证，不能因为原论文不以它为目标而排除。

## 汇总规则

父候选在本轮启用的任务范围内，制备状态分为：有合格见证、全部相关任务完成但无合格见证、尚无见证且相关任务未完成。三类互斥，和等于候选数。

有见证且任务未完：显示“已命中，结果不完整”，分子/反应数量为已找到数量或下界。证据未知/冲突但任务完成：显示“未找到合格见证，并有待核实资料”，不能显示“该分子不可合成”。

所有计数携带 `scope_id`：输入目标、候选集合、规则/匹配版本、来源快照及本轮任务集合。补查新增任务后生成新的汇总版本，不把旧范围的总数和新范围命中混合。

候选流读完、选择范围穷尽、整个家族穷尽分别记录。相似 Top-K 列表读完只表示该列表结束；不能使尚未搜索的质量窗口或家族范围变为完整。来源行读取完成但存在未能解析/关联的相关记录时，注明验证缺口；坏记录既不作为合格见证，也不作为阴性实验。

摘要的展示裁剪与上述检索完整性独立。每个送入模型的结论须连同其实际/推定类型、证据范围、关键未知/冲突和出处一起保留；不能把“图回放符合目标，条件尚未验证”裁成“可以合成目标”。若摘要容纳不下完整结论单元，减少条目并报告省略数，不改变冻结证据池或原始命中统计。

[验收场景](../reviews/evidence_contract_cases.json)是人工编写的逻辑样例，不是文献数据。现阶段仅验证其格式和定义一致性，行为需由未来实现执行并与期望比对。

## 目标连接方法的资格

结构见证与连接方法见证分开。每条候选按 [连接方法规范](attachment_methods.md)输出实际反应类型、目标位点、边界变化及底物角色。支链本来已接在核心上而本步只作其他修饰时，不是本连接目标的方法见证。缺少两侧或局部映射支持可返回未知，但不升级为阳性方法。

方法计数按连接目标与实验汇总，替代边界单独记录，分区改变不制造同一边界的新证据。对精确/局部核心与支链的覆盖、反应类别依据、观察结果和迁移差异分别报告，不输出可迁移性的伪概率。

## 单反应物替换建议不是来源见证

按 [替换类比规范](single_reactant_transfer.md)生成的建议携带来源反应、原/替代槽位、目标差异、回放及条件状态。原反应是事实，替代底物和新转化是规则推定；二者不共享实验身份，也不将虚拟产物计入制备或连接方法命中。推定建议可引用真实底物资料，但来源资料不证明新组合已经成功。

## 已有反应的开闭环证据

结构范围先决定召回，环变化标签来自实际候选反应分析，见 [专项规范](acyclic_and_topology_search.md)。默认不预先枚举目标环变化位置或生成虚拟前体。每个阳性标签需要源反应两侧证据、实际方向和目标相关位置对应；仅环数差或支链相似度不足以成立。

源开环断键不在目标产物中时，保留其源键及保留原子对应，不伪造目标中已有该键。反应分析完成状态、结构召回完整状态和化学未知状态分开。来源之后的替换类比继续单列为推定，不回流到事实计数。

## 排序证据与实验适配

按 [独立排序规划](../ranking_plan.md)，实际条件、危险信息、分子量、价格等特征带材料/阶段/规模/日期与来源。能力限制匹配采用通过/不符合/未知/不适用；没有实验配置不声称适配，未知危害不等于低风险。类比建议不继承来源反应的收率或安全/可行性结论。高参考价值与适合当前实验条件分别输出，证据本身不因切换排序偏好而改变。

## Markush 家族见证

按 [家族查询规范](markush_queries.md)，家族是查询表达，具体分子与实验是证据。多个 R 条件须由同一实际分子和一致核心映射见证；单个位点取值曾出现不支持其任意组合已被制备。来源通式命中只说明有结构范围线索，具体获得/方法计数仍需具体实例。家族宽松性、未支持约束和遍历截断分别返回，不能静默当作全部条件成立。
