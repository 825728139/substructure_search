# 反应来源字段与接入约定

核对日期：2026-10-28。来源处于全量入库过程中。当前两个反应表的字段足够支撑首版参考检索，读取适配器尚待实现。本文件描述已核对的来源契约和接入注意事项，不规定数据库迁移。

## 1. 字段用途

| 来源字段 | 检索系统用途 |
|---|---|
| `reactions` 的来源组合键与 `id` | 文档/段落/反应定位；内部关联与分页 |
| 五类 `*_smiles` 数组、`products_mol`、`reactants_mol` | 获取候选结构及材料角色，做结构预筛 |
| `reaction_smiles` | 无映射反应式展示与结构比较 |
| `mapped_reaction_smiles` | 实际键变化、原子来源及目标母核—支链连接分析 |
| `reaction_center_r1`…`r4` | radius 1–4 的局部反应模板，方向为产物 → 反应物；不是 Markush R 位点 |
| `product_fp`、`reactant_fp` | radius=2、2048 位 Morgan 相似度补充 |
| `reaction_details` 的五类 JSONB 材料数组 | 具名材料对象：名称、结构、用量及额外提取字段 |
| `raw_reaction` | 原始反应 JSON；保留缺失/null/空串与原始类型 |
| `aam_result` | 完整原子映射结果、来源文件/下标、审核状态、评分及原因 |
| `role_resolution` | 原角色和序号、供体角色调整、映射重数及规则版本 |
| 条件文本、范围数值、收率、气氛、类别 | 有值时筛选或解释；缺失时保留未知 |
| `reaction.evidence` | 关联原文证据，核查实验归属和未提取信息 |

用户提供的提取结果目录为 `/mnt/data2/patent-reaction-results/epo` 和 `/mnt/data2/patent-reaction-results/uspto`。读取适配器优先使用已入库记录及其来源标识；原始文件路径不代替反应实例与证据关联。

## 2. 读取与分析顺序

先从 `reactions` 取得轻量候选，核验具体分子的核心与联合支链约束，再批量关联 `reaction_details` 和原文。完整 AAM 对象较大，仅对进入分析阶段的候选加载。

材料实例以来源、角色、条目序号和版本定位。盐的图组分与实际投料实例分开；不按 `reaction_smiles.split('.')` 恢复材料角色。由映射提升为供体的角色保留推断来源；配平副本不自动当作实际投料份数或当量。

源反应模板可以描述多个产物，模板自检使用完整产物侧；Markush 联合要求仍必须落在同一实际分子的同一核心映射中。具体匹配与方法贡献按 [家族规范](markush_queries.md)、[连接方法](attachment_methods.md) 和 [证据契约](evidence_contract.md) 执行。

## 3. 质量与连接参数

- **映射质量**：解析成功、元素一致或多个映射器一致，都不单独证明化学正确。保留局部核验和来源审核状态；异常模板仍可提供结构/原文参考，不能直接证明迁移可行。
- **评分含义**：当前导入门槛为 `final_score >= 5`；`aam_result` 内可能保留门槛 12 的审核结果。入库策略、源审核状态及目标参考价值分别处理，不把总分当作合成成功率。
- **条件与类别**：空值不等于常温、容易、安全或无变化。可先返回结构、底物、实际变化和原文，条件/类别后续从有出处的信息补齐。
- **指纹配置**：存储为 2048 位，新连接默认仍为 512 位。相似度查询显式对齐半径、位数与版本；Morgan 相似度阈值不作为 Markush 必经硬过滤。
- **服务就绪检查**：入库期间只观察到主键和来源键索引；正式检索前确认 mol/fp 索引、统计信息和典型执行计划。该观察不代表导入结束后的索引状态。
- **快照**：来源持续写入时，候选页、两表详情和原文使用同一个适配器一致性令牌；仅保存查询时间或最大记录 ID 不足以固定已有行的内容。

当前 PostgreSQL 来源可由适配器在 run 的有限读取期限内使用同一只读 Repeatable Read 会话；不让不同连接的默认 Read Committed 分页被当作同一快照。源读取结束后释放会话，将实际使用的记录、映射和证据按内容哈希冻结到 run。连接断开/重启后不能只靠记录的事务标识重建旧快照；已有候选可封存或重排，后续来源查询需新 run 或可恢复的固定导出。事务语义依据 [PostgreSQL 18 文档](https://www.postgresql.org/docs/18/transaction-iso.html#XACT-REPEATABLE-READ)，这里规定的是读取方式，不修改源库。

## 4. 验证范围与已知问题

2026-10-28 14:28 的有限样本为较早 120 条和较新 180 条，覆盖 15 篇文档（EPO 181 条、USPTO 119 条），不是随机样本或全库质量估计。

300 条均具备完整映射、原始 JSON、AAM 结果与角色记录；映射解析、产物对应、元素/同位素一致、两侧映射标签唯一和五类材料身份/重数检查通过。四种半径的源产物侧连接关系自匹配均通过。

当前样本需要保留以下状态：

- 4 条记录的部分模板严格手性自匹配不通过：`id=7、106419、106430、106433`。复核前不据此证明立体迁移。
- 条件字段和原始 JSON 对应值均为空/缺失；原文抽查包含温度与时长，补充应回到上游提取或证据。
- 24 条源审核状态为 `filtered`，属于源审核门槛与当前入库门槛不同；不直接混作审核通过或导入错误。

可复现的计数与异常编号见 [样本摘要](../reviews/reaction_source_audit.json)，检查入口见 [验证说明](../reviews/README.md)。这些检查没有验证全库化学准确率、模板迁移成功率或实验可重复性。
